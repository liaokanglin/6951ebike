### 命令定义

命令控制发送/ 接收方向：

- 以 **CMD_SET**、 **CMD_GET** 前缀的命令控制方向是： SOC -> 蓝牙模块。
- 以 **CMD_REPORT** 前缀的命令控制方向是： 蓝牙模块 -> SOC。 
- 以 **CMD_ACK**前缀的命令为应答命令， 蓝牙模块在收到命令帧后根据实际接收情况发送应答帧， 应答帧的**Frame_id** 应和接收到的命令帧 **Frame_id** 相同。

车机方案定义如下传输通信命令

#### CMD_ACK_OK(蓝牙应答)

| Cmd_id | Cmd_value_len | Cmd_value |
| :----: | :-----------: | :-------: |
|  0x00  |       0       |     0     |

描述： 应答命令， 接收方用于应答发送方的数据帧接收成功， 无数据域。

备注： 通常用于蓝牙端应答来自SOC端发送的**CMD_SET** 等相关命令； 当蓝牙端收到**CMD_SET** 等相关命令且**CMD_SET** 等命令执行成功后，蓝牙端需告知SOC端 **CMD_ACK_OK**用于应答**CMD_SET** 命令执行成功。

命令示例：`AC 69 0a 00 00 00 00 00 1F 01`

#### CMD_ACK_ERR (蓝牙错误应答)

| Cmd_id | Cmd_value_len | Cmd_value |
| :----: | :-----------: | :-------: |
|  0x01  |       1       | ERR_CODE  |

描述： 应答命令， 接收方用于应答发送方的数据帧接收失败， 需要发送方重新发送。 失败原因见命令数据域，常见ERR_CODE 具体见如下定义：
ERR_CODE 定义： 
1--ACK_ERR_CHECKSUM： 校验和出错； 
2--ACK_ERR_CMD_ID： 不支持的命令； 
3--ACK_ERR_INCOMPLETE_FRAME： 不完整的数据帧； 
4--ACK_ERR_CMD_FORMAT： 命令格式有错误；
5--ACK_ERR_CMD_CANNOT_EXECUTE： 当前命令不能执行；
6--ACK_ERR_CMD_BT_MODE_ERR: 当前运行模式错误，不能执行

... ... （后续ERR_CODE 待添加）

备注：通常用于蓝牙端应答来自SOC端发送的**CMD_SET** 等相关命令； 当蓝牙端收到**CMD_SET** 等相关命令且**CMD_SET** 等命令执行失败后，蓝牙端需告知SOC端 **CMD_ACK_ERR**用于应答**CMD_SET** 命令执行失败。

#### CMD_REPORT_HID_DEVICE_STATUS

| Cmd_id | Cmd_value_len |            Cmd_value            |
| :----: | :-----------: | :-----------------------------: |
|  0xb8  |     1 + n     | CONNECT_STATUS + CONNECT_DEVICE |

描述： 蓝牙模块告知SOC端 当前HID设备的连接状态， 用于应答`CMD_GET_HID_DEVICE_CONNECT_STATUS`  命令，数据域表示设备的具体连接状态。当手机端断开和蓝牙模块的连接时，模块应主动上报自身的连接状态。

CONNECT_STATUS定义（1 个字节） ： 
0 --DISCONNECTED_STATUS： 当前处于断开状态
1 --CONNECTED_STATUS： 当前处于连接状态

CONNECT_DEVICE 定义（n 个字节）：
